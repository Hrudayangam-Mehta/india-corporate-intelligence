# India Corporate Intelligence Platform

## Overview
Mapping every company, connection, and influence in Indian business.

## Live Demo
*Coming soon*

## Repositories
- `india-corporate-intelligence` — Main web application
- `icip-data-pipeline` — Data collection and ETL
- `icip-network-engine` — Graph analysis engine

## Data Coverage
- **NSE Listed**: ~1,700 companies
- **BSE Listed**: ~5,000+ companies
- **Documents**: 5-year annual reports
- **Networks**: Directors, promoters, political, media

## Features
- Interactive India map (state/city/company drill-down)
- World map (FDI, ports, foreign subsidiaries)
- Network graph (interlocks, influence, ownership)
- Political connections (electoral bonds, donations)
- Media ownership and coverage analysis
- Industry deep dives with supply chain mapping
- Timeline tracking and alerts

## Tech Stack
- React 18 + TypeScript + Vite
- Tailwind CSS v4
- Mapbox GL JS + D3.js
- DuckDB (client-side analytics)
- Node.js + PostgreSQL

## Development
```bash
npm install
npm run dev
```
